Original and converted model

Original model: stdo/PengChengStarling, linked by the PCL-Voice project.

Fangjun Kuang (csukuangfj) / sherpa-onnx converted the encoder and joiner to INT8 using ONNX Runtime dynamic quantization. The decoder, BPE vocabulary and tokens retain their original file identities. The app downloads the converted model from an immutable revision, c6726c1147387ad2a11148b33973135d92a55e6c, and checks each file's full SHA-256. The converted repository has no separate license metadata; the original model's Apache-2.0 grant is the stated basis, with the identifiable conversion recorded above.

Runtime and local modifications

The ASR-only Sherpa-ONNX 1.12.32 runtime is Apache-2.0. CooTrio changes the build to omit bundled weights and applies the author's Thai decoder start token, <TH> (ID 8), before decoding. These runtime modifications do not alter the model weights. The runtime and its license are retained under src/vendor/sherpa-pengcheng-1.12.32-th/.

The project does not bundle the unlicensed PCL-Voice training toolkit. Its lack of a repository-wide LICENSE file must not be treated as a license for that training code.
